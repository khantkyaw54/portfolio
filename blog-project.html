My Blog

使用技術：HTML / CSS / JavaScript / Wordpress

制作期間：2025.7 - 2025.09

概要

ブログサイトをイメージして制作したWebサイトです。 ブログ記事の投稿やカテゴリー分けなど、基本的な機能を実装しました。

工夫した点

ブログサイトの構築にあたり、ユーザーが記事を簡単に投稿できるように、Wordpressのカスタム投稿タイプやカスタムフィールドを活用しました。 また、カテゴリー分けやタグ付けなどの機能も実装し、ユーザーが記事を整理しやすいように工夫しました。

課題と解決

ブログサイトの構築にあたり、記事の管理やカテゴリー分けなどの機能を実装する際に、Wordpressのカスタマイズが必要でした。 これらの課題を解決するために、Wordpressのドキュメントやコミュニティを活用し、必要な機能を実装しました。
